# 图书深度领读创作规范与工作流

## 一、核心原则

1. **全文本问答推演**：领读报告以“问：”“答：”推进全篇。问句短而准，承担引路、质疑、反驳或转折；答句成段展开，构成一条前后咬合的连续追问线索。
2. **先定判断，再给理由**：每组问答先在首句亮出清晰可判断的结论，再铺开推理链条与事实依据，让读者一眼抓住立场与答案。
3. **连贯段落承载逻辑**：正文默认采用连贯自然段，依靠“因为、但是、除非、也就是说、结果”等逻辑连接词呈现因果转折。仅在比较多个维度、列举操作步骤或汇总章节索引时使用并列结构。
4. **文本忠实与认识论分层**：所有命题、案例与数据严格来自原书文本，显式区分三类边界：
   - **作者原意**：文本明确给出的核心判断与证据链。
   - **引申**：顺着作者逻辑向前推进的推论或跨时代对照。
   - **推断 / 保留标注**：作者在样本有限或缺乏实证处做出的经验推论，以及需要读者自行补足的历史前提。
5. **原文忠实与出处透明**：Key20 的中文引文（`propositionZh`）必须是原书底本（`artifacts/sources/<slug>.md`）中的**可核查原句或以 `……` 衔接的精确节选**，禁止用读者自己的总结改写冒充原句。出处类型统一分为三类：
   - **中文原著原句（`chinese-original`）**：如《乡土中国》等中文原著，直接摘录原文，不附英文，可按需补充核心概念注记（`conceptNote`）。
   - **原书原句（`original`）**：外文译著且底本或权威原版已核验到精确英文原句。
   - **英文回译（`back-translation`）**：底本仅含中译文时，中文必须严格摘自译本原句，英文回译句末尾须显式标注 `（回译）`（或 `（回译自文中引……）`），保证引用透明可核查。

## 二、写作与表达准则

### 1. 从具体现场长出概念
- 开篇直接落进一个真实、反常或令人困惑的具体场景，展示常规直觉在何处失灵，迫使抽象概念作为“唯一能解开僵局的工具”自然登场。
- 避免以宏观背景介绍、作者生平赞美或高度概括的术语清单作为开场。

### 2. 真实抵抗型的追问
- 问句代表聪明且持怀疑态度的读者发声：提出合理的常识反驳、温和的改良幻想、或指出前一段论证暴露出的逻辑缺口。
- 问句之间保持因果推进，使上一问的结论刚好逼出下一问的困惑。

### 3. 事实链条先于总结标签
- 面对反常识事件或历史对照，先按时间顺序或现场细节还原两个版本的具体冲突与转折，待事实张力自然浮现后，再收拢出核心概念。

### 4. 深挖少数核心切片
- 全篇围绕 4 至 6 个最具穿透力的原书现场反复深挖，让同一组关键切片在理论奠基、机构剖析与全书收束的不同阶段发挥多层作用，取代走马观花式地罗列大量孤立案例。

### 5. 坦诚的读者立场
- 解读遇到作者未明言的史料盲区、时代局限或时代迁移后的新问题时，直接在正文中以第一人称标明个人理解，用平等对话的口吻划清作者方法的适用边界与不可保证之处。
- 结尾保持与全书论证一致的克制，当文本本身没有提供廉价解决方案时，如实交代困境所在。

## 三、内容模块规格

每部书的深度领读产出固定由三个核心模块组成，既可独立成篇，也可合并为“全篇连读”：

### 模块一：论证地图与边界意识
- **目的地与图例**：用一句凝练且有张力的总判断重述全书终极核心命题，配以分步路径概览。
- **递进节点（5 至 7 步，推荐 6 步）**：
  - 节点编号统一采用 `起点 / 第 1 步 … 第 N 步 / 终点`，并配备简洁的 `shortLabel`（4–12 字）供侧边目录导航使用。
  - 每步对应原书连续章节区间，包含：步骤编号与标题、尖锐问句、直截了当的首句判断、2 至 3 段由现场案例与推理织成的连贯正文，以及明确指向下一步困惑的过渡桥接语。
- **边界意识双栏对照**：
  - 左栏梳理“作者的方法能推出什么”（不依赖阴谋论或表层归因的结构性因果链，以及作者主动划定的理论克制）。
  - 右栏梳理“回看时不能保证什么”（原书的历史采样偏差、所处时代的媒介局限，以及放到当代语境后出现的新变量）。

### 模块二：洞见概览
- **终极核心命题**：先以问答引出能吸纳全书所有章节的单一核心命题，再用两段连贯分析交代该命题如何统领全书前、中、后三段推进。
- **章节核心命题**：按原书实际前言与各章顺序逐单元提炼，每章包含：
  - 简洁的 `shortLabel` 与一句短而可判断的核心命题（指明该章回答的问题与颠覆的常识）。
  - 一段连贯叙述（把核心论据、关键细节与章节推进自然揉成整段，不使用重复的表单字段）。
  - 可选的“引申 / 推断 / 保留标注”补充段落，专门安放超出文本明言边界的思考。

### 模块三：Key20 反常识原典句库
- **主题编组（4 组）**：按论证重心将 20 条关键原句分为 4 个逻辑群组，每组配备简洁 `shortLabel`、`rangeLabel`（与组内条目序号严格对齐）以及引路问答，说明这几句话在整套论证中的共同任务。
- **单条句库规格（共 20 条）**：
  - 编号（`01`–`20`）、所属章节、可逐字核验的中文原书原句或精确节选（`……`）、对应英文原句或带 `（回译）` 标注的英文回译（中文原著不附英文，可附 `conceptNote`）、出处类型（`original` / `back-translation` / `chinese-original`）。
  - 一段紧贴原书切片的精析，点明它拆掉了哪条流行常识，以及在全书体系中的承重位置。

## 四、五阶段标准工作流

### 阶段一：通读源文本与切片建档
1. 完整读取原始书稿或权威译本全文，逐章摘录关键史料、数字、人物事件与作者亲口划定的边界声明。
2. 筛选出 4 至 6 个贯穿全书、细节饱满的“高密度现场切片”，记录其发生时间、人物、精确细节与反常之处。
3. 收集 20 至 30 条最具有翻转常识力度的原句，核对其英文原文或明确标记回译性质。

### 阶段二：锚定终极命题与分章标尺
1. 提炼全书“终极核心命题”，确保每一个分章命题都能向该命题收束，形成折叠展开的关系。
2. 逐章写出“核心命题 + 连贯叙述”，将作者原意与读者回看产生的“引申 / 推断 / 保留标注”剥离并单独标记。

### 阶段三：设计追问弧线与撰写论证地图
1. 选定全书最令人意外的“失效现场”作为论证地图的起点，以此提出第一个直觉悖论。
2. 沿着“日常归因失效 → 建立认识论前提 → 历史对照验证 → 现实机构解剖 → 逃生幻想破灭 → 边界回看”的逻辑主轴，串联起全部地图节点。
3. 撰写每一节点的问答正文，确保每步结尾的过渡语能严丝合缝地咬住下一步的开篇问句。

### 阶段四：精修语言与认识论复核
1. 通读全部正文，将任何碎裂的条目清单改写为因果饱满的自然段，检查每段回答是否先亮出判断再展开论据。
2. 核对所有数据、人名、时间与引号是否与源文本完全吻合；检查“作者的方法能推出什么”与“回看时不能保证什么”是否保持客观平衡。
3. 清理一切脱离文本的空洞感叹、套话与重复的解释性装饰语。

### 阶段五：结构化入库与自动化验收
1. 将定稿按 `BookReadingDataset` 契约写入 `content/reading/books/<book-slug>.ts` 并统一导出 `BOOK_DATASET`；在 `content/reading/metas.ts` 登记唯一一份轻量元数据，在 `content/reading/catalog.ts` 注册动态 `import()`，在 `content/reading/registry.ts` 挂接该书 `BOOK_DATASET`。
2. 运行 `npm run lint && npm test && npm run build && npm run audit`，由单测与审计脚本自动核查结构完整性、Key20 原文逐段匹配度、目录锚点、`catalog/registry` 同步及公开站隔离性，并在桌面端与移动端浏览器中实地通读。

## 五、交付验收清单

- [ ] **全篇线索连贯**：任意抽读连续三组问答，上一答末尾均能自然迫出下一问。
- [ ] **现场驱动概念**：论证地图开篇即进入具体事件现场，不以抽象定义开场。
- [ ] **结论前置清晰**：每段回答首句均为可独立成立的判断，随后才展开事实与推演。
- [ ] **事实零编造**：所有人名、年份、数据与引用均可追溯至给定原书材料，回译句均明确标注。
- [ ] **边界清晰透明**：作者原意、引申、推断与读者当代回看各有明确落点，互不混淆。
- [ ] **结构化可读**：同时适配纯文本通读与网页分模块（论证地图、洞见概览、Key20、全篇连读）阅读。
